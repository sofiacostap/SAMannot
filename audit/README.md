# Ruff tracking evaluation — start here

This branch contains the SAMannot application plus the Lek4 research audit.
**Read the [task dashboard](docs/README.md) for the current state.**

- [Project overview and findings](docs/PROJECT_OVERVIEW.md)
- [Script catalogue: current, supporting and historical](docs/SCRIPTS.md)
- [Results catalogue: which runs to use](results/README.md)
- [Repository guide](docs/REPOSITORY_GUIDE.md)

Documentation is grouped under `docs/tasks/`. Executable scripts stay in this
directory to preserve imports and existing Lumen commands. Results and machine
manifests keep their original paths and checksums. Historical investigations
are explicitly marked under `docs/archive/`; they are not the current workflow.

The released baseline has 14,175 evaluation observations. No proposed identity
correction has been applied. See the dashboard for limitations and pending work.
