Instructions and what acceptance means

Arrow keys move one image; Space plays/pauses. A accepts only the still-pending birds in the current frame. Playback waits for each image to load and never changes decisions. Pause to inspect; use full pixel size and isolate an ID for boundaries or occlusion.

Accepted present = this GT identity and its visible mask look correct. Accepted absent = no mask is appropriate for this identity (including complete occlusion, if justified). Uncertain = identity/boundaries/presence cannot be resolved. Confirmed problem = a visible GT error. Add a reason for either flag and click Save for that bird.

Previous automatic screening is shown for context, but every observation begins unreviewed. Reaching the last frame is not completion. Reviewed includes flagged observations; unresolved counts pending, uncertain and confirmed problems. A complete review is not a guarantee of error-free biology. Changes to the evaluation reference need a separate release.

Decisions save to review.json on this computer after each action. Stop with Ctrl+C in the terminal; use --resume with the same review folder to continue. Keep the browser tab open while reviewing. Playback speed depends on image decoding and is not real-time video speed.
